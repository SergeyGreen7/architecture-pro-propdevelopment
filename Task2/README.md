# Задание 2. Проверочный лист безопасности бизнес-систем

## Главные проблемы, которые нужно решать в первую очередь:

- нет разграничения доступа к данным: чужие данные в ЛК, у партнёров и в Хранилище (I.4, I.7, V.2);
- нет учёта ПДн и Data Governance, сырые ПДн уходят в Хранилище (II.7, II.9, II.13);
- нет единого реестра учётных записей и единой точки регистрации клиента (I.11, II.15*);
- нет процесса реагирования на инциденты, ИБ не участвует во всех изменениях (IV.2, IV.3, V.6).

## Проверочный лист

Статусы: **Да** — выполняется, **Нет** — не выполняется, **Частично** — выполняется не полностью, **Нет данных** — в описании нет информации, нужно уточнить у команд.

## 4. Итог

Подтверждено только два пункта: резервное копирование всех БД и вход пользователей через firewall.


Большая часть вопросов по инфраструктуре, Kubernetes и шифрованию отмечена как «Нет данных» — их нужно уточнить у команд в ходе аудита.
